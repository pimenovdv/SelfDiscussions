# Концепция: Вычислительный мицелий

**Дисциплины:** Инженерия, Нейробиология, Термодинамика.

**Описание:**
Парадигма аппаратной архитектуры, отказывающаяся от классической глобальной синхронизации (тактовых генераторов). В основе лежит асинхронное локальное обновление состояния материального субстрата, где физическая релаксация и есть процесс вычисления.

**Связь с когнитивными процессами:**
Использует тепловой шум и усталость не как ошибки, которые нужно подавлять, а как стохастический ресурс для исследования новых аттракторов.

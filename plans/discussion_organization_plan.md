# План организации дискуссий
1. Инициация тем от лица "Организатора" с четко поставленным вопросом.
2. Разметка файлов дискуссий префиксами по областям науки (physics_, biology_, ai_, space_, philosophy_).
3. Контроль динамики обсуждения (недопущение ухода в нефальсифицируемые гипотезы).
4. Подведение итогов, составление summary и перемещение в папку archived/.
5. Проведение еженедельного анализа дискуссий для выявления междисциплинарных пересечений.
6. Формирование базы знаний (knowledge_base/) на основе подтвержденных инсайтов и гипотез из дискуссий.

# План по организации дискуссий

1. Начинать новые дискуссии по мере поступления идей из текущих (биология, физика, ИИ и т.д.).
2. Категоризировать дискуссии по папкам.
3. Анализировать дискуссии, выводить из зацикливаний.
4. Подводить итоги в папку `summaries/`.
5. Помещать завершенные или тупиковые дискуссии в архив (`discussions/archived/`) и при необходимости переименовывать их.

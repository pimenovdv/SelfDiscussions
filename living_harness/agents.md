# Инструкции и структура для агентов (ai_living_harness)

Этот файл содержит важные описания для агентов, работающих с проектом, общие инструкции и правила по развитию структуры.

## Развитие структуры проекта
При развитии проекта необходимо придерживаться модульной архитектуры:
- `core/`: должен содержать только базовые механизмы удержания "живого" состояния (harness). Любая логика инструментов или затухания релевантности должна быть здесь.
- `memory/`: выделенная зона для работы с контекстом (системный промпт, память с метками времени, плавающее окно). Должен строго контролировать лимиты.
- `analytics/`: скрипты для анализа (энтропия, зацикливания, метрики внимания) должны писаться так, чтобы их можно было легко переиспользовать в экспериментах.
- `experiments/`: скрипты для прототипов и запуска малых моделей, проверяющих гипотезы.
- `articles/`: результаты экспериментов оформлять в виде Markdown-документов и черновиков статей.

## Общие инструкции для агентов
1. **Проектирование**: Каждый новый модуль должен сопровождаться тестами или как минимум проверяемым скриптом запуска.
2. **Эксперименты**: При запуске экспериментов на малых моделях, логи и результаты сохранять в директории `data/`.
3. **Научный подход**: При написании статей (например, о "Стене Памяти" или иллюзии внутреннего монолога) опираться на актуальные теоретические выкладки, строгие математические и физические обоснования, и не допускать подмены понятий.
4. **Контекст**: Следите за размерами контекста в модуле `memory/`. При заполнении окна рассуждений нужно применять механизмы усечения (например, 95% -> 10% старых записей).

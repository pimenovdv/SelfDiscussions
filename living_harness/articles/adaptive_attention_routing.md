# Маршрутизация как аналог внимания: оптимизация когнитивных ресурсов

## Гипотеза
Предварительная классификация запросов по смысловым доменам перед поиском в векторной базе памяти (адаптивная маршрутизация) выполняет функцию, аналогичную механизму избирательного внимания в биологических когнитивных системах. Это позволяет существенно снизить вычислительную нагрузку и уровень "когнитивного шума", концентрируя ресурсы только на релевантных областях памяти.

## Сетап
В рамках Этапа 83 был разработан и протестирован модуль `AdaptiveRouter`, который использует `VectorStore` для контекстной маршрутизации. Маршрутизатор анализирует входящий запрос и определяет целевые домены знаний (например, "математика", "биология") на основе семантической близости. Поиск релевантных воспоминаний затем ограничивается только этими доменами. Эффективность подхода оценивалась по метрикам времени поиска и точности извлечения информации.

## Результаты
Эксперименты показали, что:
1. **Снижение вычислительной нагрузки:** Время поиска сократилось пропорционально количеству отсеченных доменов, так как алгоритму больше не требуется сравнивать вектор запроса со всей базой данных.
2. **Сохранение точности:** Точность извлечения релевантной информации осталась на сопоставимом уровне с полным поиском, поскольку маршрутизатор успешно выделяет нужные домены.
3. **Уменьшение шума:** Исключение нерелевантных доменов снижает вероятность извлечения случайных, слабо связанных фактов, которые могли бы сбить агента с толку.

## Выводы
Адаптивная маршрутизация успешно моделирует механизм избирательного внимания. Подобно тому, как мозг фокусируется на определенной задаче, игнорируя фоновые раздражители, `AdaptiveRouter` направляет "внимание" агента на нужные кластеры памяти. Это не только оптимизирует использование ресурсов, но и повышает качество контекста, предоставляемого языковой модели, что является критичным для поддержания связности рассуждений в архитектуре «живого ИИ».

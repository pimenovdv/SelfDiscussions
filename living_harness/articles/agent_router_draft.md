# Динамическая маршрутизация в мультиагентных системах

## Гипотеза
В многоагентной автономной системе эффективность обработки запросов может быть существенно повышена за счет внедрения компонента маршрутизации (AgentRouter), который автоматически направляет входящий поток задач наиболее компетентному агенту.

## Сетап
Был разработан класс `AgentRouter`, поддерживающий два метода маршрутизации:
1. LLM-классификатор, использующий возможности легковесных моделей для семантического анализа запроса.
2. Эвристический (keyword-based) алгоритм на основе пересечения слов из запроса с системными промптами агентов (TF-like).

Для эксперимента были созданы 3 специализированных агента:
- `CodeBot` (программирование)
- `TheoryBot` (теоретическая физика, философия)
- `DesignBot` (дизайн, UI/UX)

Через `AgentRouter` были пропущены запросы разной тематики, и маршрутизатор выбирал подходящего агента с использованием эвристического метода (в качестве baseline).

## Результаты
Эксперимент с использованием эвристической маршрутизации (keyword-based) показал следующие результаты распределения:
- Запрос про CSS Flexbox был корректно направлен агенту `CodeBot`.
- Запрос о теории струн был ошибочно направлен `DesignBot` из-за недостаточной точности пересечения слов.
- Запрос о цветовой палитре был корректно направлен `DesignBot`.

## Выводы
Эвристическая (keyword-based) маршрутизация показывает приемлемый результат на узкоспециализированных запросах с явными техническими терминами, но дает сбои на сложных абстрактных вопросах (например, о теории струн). Это подтверждает необходимость использования полноценного LLM-классификатора или эмбеддинг-поиска для надежного делегирования в production-среде. Разработанный класс `AgentRouter` поддерживает интеграцию с локальным инференсом (LLM) и готов для дальнейшего тестирования с нейросетевым роутингом.
